Release notes

Every version downloads and installs the next one by itself. The archives of all versions remain available on GitHub.

1.5

  • A stalling stream is now detected — silence, or a rate fallen below half of real time. Kodama cuts and reconnects instead of sitting on choppy playback. The silence delay is configurable.
  • Kodama gives up and says so when a station stays unreachable, instead of retrying forever. The delay is configurable; zero never gives up.
  • The reason for a dropout is shown: server not found, connection refused, certificate refused, the station's status code. Failures that will not fix themselves stop right away, and the screen says so rather than reconnecting forever.
  • A log, under ~/Library/Logs/Kodama/, opened from the menu. That is what to attach to a report.
  • A station that announces no titles no longer stays shown as “Reconnecting…” once the sound is back.

1.4

  • A recorded track is named after its station, the date and the time — Groove Salad - 2026-09-01 10h01 - Artist - Title.mp3 — instead of a running number. Sorting by name therefore groups by station, and follows listening order within each. Tracks already recorded are not renamed.
  • The track playing when you connect is now recorded too, missing whatever went out before. Its title carries “(partial)”. It is still subject to the minimum duration threshold.
  • The title shown in the Recordings window is read from the file rather than from its name: renaming a track in the Finder no longer changes what Kodama shows.

1.3.2

  • A support link in the “About” panel, for anyone who feels like buying a coffee. Nothing else changes.

1.3.1

  • The “About” panel is now the same whether it is opened from the menu bar or from the application menu.

1.3

  • A right-click on the menu bar icon opens the window. Left-clicking opens the menu, as before.

1.2

  • ⌃⌥⌘R opens the window, wherever the cursor is: the shortcut is system-wide, unlike the menu's ⌘O.
  • The shortcut can be changed in Settings, under Keyboard. Esc leaves none.

1.1

  • The site is now at steveoctets.github.io, and that is where this release looks for updates.
  • An “About” entry in the menu: the installed version, and a link to the site.

1.0

  • Search among fifty-eight thousand radios, in the public radio-browser.info directory: by name, by country or by genre. A button on each result queries the station and says whether it broadcasts its titles, and so whether Kodama will be able to record it.
  • Detection of recordable radios reads the stream until it gets a real title, rather than trusting a header.
  • Recording can be turned off for one radio, from its own sheet.
  • The pending list disappears when the station being played will produce no tracks.
  • Updates say what they bring: this very window.

Fix: editing a stopped radio then starting it again replayed the old version, recording setting included.

0.10

  • Launch at login. Kodama can now start when you log in, from its Settings. It sits in the menu bar, playing nothing.

The switch reads the actual state held by macOS rather than a copy of it: turning Kodama off from System Settings → General → Login Items shows up straight away in the app.

0.9

The first public release.

  • Ten stations to start with, installed on first launch — ambient, chillout, electronica, downtempo. All of them broadcast track titles, so recording works.
  • Automatic updates. Kodama tells you about new versions and installs them.
  • English and French interface, following the system language.
  • Configurable user agent: some stations only open their stream to an agent they recognise.

Universal binary, Apple silicon and Intel. Signed and notarised by Apple.
