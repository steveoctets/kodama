Versions

Chaque version télécharge et installe la suivante d'elle-même. Les archives de toutes les versions restent disponibles sur GitHub.

1.2

Un raccourci qui marche vraiment.

  • ⌃⌥⌘R ouvre la fenêtre de Kodama où que vous soyez. Le ⌘O du menu ne répondait que si une fenêtre de Kodama était déjà devant — autrement dit quand on n'en avait plus besoin : les raccourcis d'une application ne valent que lorsqu'elle a le focus, et une application de barre des menus ne l'a presque jamais. Celui-ci vaut pour tout le système.
  • Il se change dans les Réglages, section Clavier : un bouton Modifier…, la combinaison que vous tapez, et Échap pour n'en avoir aucun. C'est nécessaire — un raccourci global peut entrer en conflit avec une autre application, et la première lancée garde la main.

1.0

La première version que j'assume comme finie.

  • Chercher une radio parmi cinquante-huit mille. Kodama interroge l'annuaire public radio-browser.info, par nom, par pays ou par genre. Un bouton par résultat interroge la station elle-même et dit si elle diffuse ses titres — donc si Kodama saura l'enregistrer. L'annuaire, lui, ne le sait pas.
  • La détection des radios enregistrables est bien plus sûre. Elle lit désormais le flux jusqu'à obtenir un vrai titre, au lieu de se fier à un en-tête : sur seize stations tirées de l'annuaire, trois l'annonçaient sans jamais rien envoyer.
  • Couper l'enregistrement d'une radio en particulier, depuis sa fiche. Pour les cas que la détection ne peut pas voir — une station qui annonce un titre sans jamais en changer.
  • La file d'attente s'efface quand la radio écoutée ne produira aucun morceau, plutôt que de rester vide sans explication.
  • Les mises à jour disent enfin ce qu'elles apportent : cette fenêtre même, qui était vide jusqu'ici.

Correction : modifier une radio à l'arrêt puis la relancer rejouait l'ancienne version, réglage d'enregistrement compris.

0.10

  • Démarrage automatique. Kodama peut désormais se lancer à l'ouverture de session, depuis les Réglages. Elle se pose alors dans la barre des menus sans rien jouer.

L'interrupteur lit l'état réel tenu par macOS plutôt qu'une copie : le désactiver depuis Réglages système → Général → Ouverture se voit aussitôt dans Kodama.

0.9

La première version publiée.

  • Dix radios pour commencer, installées au premier lancement — ambient, chillout, electro, downtempo. Toutes diffusent leurs titres, donc l'enregistrement y fonctionne.
  • Mises à jour automatiques. Kodama vous prévient des nouvelles versions et les installe.
  • Interface en français et en anglais, selon la langue du système.
  • Agent utilisateur réglable : certaines stations n'ouvrent leur flux qu'à un agent qu'elles reconnaissent.

Binaire universel, Apple silicon et Intel. Signée et notarisée par Apple.
