Versions

Chaque version télécharge et installe la suivante d'elle-même. Les archives de toutes les versions restent disponibles sur GitHub.

1.3.1

  • Le panneau « À propos » est le même qu'on l'ouvre depuis le menu de la barre des menus ou depuis celui de l'application.

1.3

  • Un clic droit sur l'icône de la barre des menus ouvre la fenêtre. Le clic gauche ouvre le menu, comme avant.

1.2

  • ⌃⌥⌘R ouvre la fenêtre, où que soit le curseur : le raccourci vaut pour tout le système, contrairement au ⌘O du menu.
  • Le raccourci se change dans les Réglages, section Clavier. Échap n'en laisse aucun.

1.1

  • Le site est désormais à steveoctets.github.io, et c'est là que cette version cherche ses mises à jour.
  • Un « À propos » dans le menu : la version installée, et un lien vers le site.

1.0

  • Chercher une radio parmi cinquante-huit mille, dans l'annuaire public radio-browser.info : par nom, par pays ou par genre. Un bouton par résultat interroge la station et dit si elle diffuse ses titres, donc si Kodama saura l'enregistrer.
  • La détection des radios enregistrables lit le flux jusqu'à obtenir un vrai titre, au lieu de se fier à un en-tête.
  • Couper l'enregistrement d'une radio en particulier, depuis sa fiche.
  • La file d'attente s'efface quand la radio écoutée ne produira aucun morceau.
  • Les mises à jour disent ce qu'elles apportent : cette fenêtre même.

Correction : modifier une radio à l'arrêt puis la relancer rejouait l'ancienne version, réglage d'enregistrement compris.

0.10

  • Démarrage automatique. Kodama peut désormais se lancer à l'ouverture de session, depuis les Réglages. Elle se pose alors dans la barre des menus sans rien jouer.

L'interrupteur lit l'état réel tenu par macOS plutôt qu'une copie : le désactiver depuis Réglages système → Général → Ouverture se voit aussitôt dans Kodama.

0.9

La première version publiée.

  • Dix radios pour commencer, installées au premier lancement — ambient, chillout, electro, downtempo. Toutes diffusent leurs titres, donc l'enregistrement y fonctionne.
  • Mises à jour automatiques. Kodama vous prévient des nouvelles versions et les installe.
  • Interface en français et en anglais, selon la langue du système.
  • Agent utilisateur réglable : certaines stations n'ouvrent leur flux qu'à un agent qu'elles reconnaissent.

Binaire universel, Apple silicon et Intel. Signée et notarisée par Apple.
